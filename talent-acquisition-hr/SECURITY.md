# Security and privacy policy for the portfolio

This repository is a public-safe **synthetic learning environment**. It is not a secure HR production system. Please never submit real candidate or employee personal information, resumes, offer documents, background check information, identity/immigration documents, medical records, credentials or API tokens as an issue, pull request or repository data file.

- Synthetic records do not model real people, employers or business transactions.
- `data/restricted` is a **logical privacy boundary demonstration** only. Public code hosting does not make that directory access-restricted. It contains fictional Group A/B/C codes, not actual protected demographics.
- No real account authorization, network ingestion, permission enforcement, encryption, audited production access or legal retention machinery is implemented.
- For a real HRIS/ATS deployment: obtain HR/Legal/Privacy/Security approval, minimize data, use a production identity layer with role-based access and data encryption, establish applicable retention and hold rules, and audit all administrative actions.
- Do not send incident details containing personal information through public GitHub issues. Use the private security reporting mechanism of any real organization that owns the data or the application.

**Scope limitation:** This project does not recommend or automatically select applicants, and should not be used to make employment decisions.
